# LDMX visual references

`ldmx.svg` is the unmodified `blue-on-white.svg` from
[LDMX-Software/logo, release 2026.02.23](https://github.com/LDMX-Software/logo/releases/tag/2026.02.23).
The upstream GPL-3.0 license is included as `LOGO-LICENSE`.
The original black-and-white design is credited to Nhan Tran by that repository;
the lettering uses Aileron.

The Studio interface takes its white background, navy `#001f3f`, and blue
`#0074d9` from the official software and blue-on-white logo variants.
This is an application design derived from those references, not a claim that
LDMX has a prescribed application design system. Detector-hit colors are
separate scientific display categories.
